# SpringHill E5 Community Portal

A community management system for SpringHill E5 residents and committee.

## Main Features

- Resident registration
- Resident approval and rejection
- Email notification for registration, approval, rejection, password reset, payments, announcements, and event promotions
- Temporary password generation
- Password reset with backend password hashing
- Resident billing details
- One-time registration fee
- Monthly maintenance fee tracking
- Stripe Checkout payment
- Stripe webhook payment update
- Official announcement listing
- Announcement email blast
- Event promotion submission
- Event approval and rejection
- Event promotion payment link
- Paid event auto-publishing
- Editable resident profile
- Banner carousel
- GitHub Pages frontend deployment
- Google Apps Script backend
